# matomeruboard

## Docs Preview

This repository includes Mermaid diagrams in Markdown files such as [docs/video-reference-share-architecture.md](./docs/video-reference-share-architecture.md).

For VS Code preview:

1. Open the workspace in VS Code.
2. Install the recommended extension `Markdown Preview Mermaid Support` when prompted.
3. Open a Markdown file and run `Markdown: Open Preview to the Side` or press `Cmd+K V`.
